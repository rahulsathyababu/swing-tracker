ℹ️ How Multi-User Sync Works
⚡ Offline-First
Every save goes to IndexedDB instantly. The app never waits for the internet. Syncs to cloud 5 seconds after each save.
🔀 Activity Merging
If two people log different activities, both are kept. If the same activity is edited by both, the most recently edited version wins.
📋 Equipment / Params
Equipment list, stage masters, and settings sync from whoever last saved them. Only one person (Admin) should edit these.
